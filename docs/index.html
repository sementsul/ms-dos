MBFU

Загрузочная флешка MS-DOS 5.00 / 6.22 за пару кликов

Скачать Исходники (MIT)

Windows · запуск от администратора · флешка до 4 ГБ (лимит FAT16)

Возможности

  • Выбор флешки: модель, размер, буква
  • MS-DOS 6.22 или 5.00, метка тома
  • Norton Commander 4.0 — опционально, по умолчанию включен
  • Обязательное принятие лицензий MS-DOS и Norton Commander
  • Блокировка системного диска и понятные ошибки вместо кодов
  • Один EXE без установки чего-либо

Как пользоваться

  1. Скачайте portable-zip из Releases, распакуйте
  2. Запустите MBFU_GUI.exe от имени администратора
  3. Примите лицензии, выберите флешку, введите ее букву
  4. Нажмите «СОЗДАТЬ» и не вынимайте флешку до надписи «Готово»

Для загрузки с флешки на современном ПК отключите Secure Boot в UEFI.
