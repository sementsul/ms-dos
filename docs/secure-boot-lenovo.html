Secure Boot на Lenovo

Отключить Secure Boot на Lenovo: Enter/F1 (ThinkPad: F1, Idea: F2 или кнопка Novo) — вкладка Security — Secure Boot — Disabled.

Пошагово

  1. ThinkPad: F1 при старте; IdeaCentre/ноутбуки: F2 или кнопка Novo.
  2. Вкладка Security — Secure Boot — Disabled.
  3. Вкладка Startup: UEFI/Legacy Boot — Both или Legacy Only для DOS.
  4. F10 — сохранить.

Нюанс

На новых Lenovo с Windows 11 может потребоваться сначала отключить BitLocker, иначе диск не прочитается.

Вопросы и ответы

Что за кнопка Novo?
Маленькая кнопка со стрелкой рядом с питанием на IdeaPad: вызывает меню с пунктом BIOS Setup без ловли клавиш.

BitLocker просит ключ после смены режима — нормально?
Да: смена Secure Boot/UEFI триггерит защиту. Либо suspend BitLocker заранее, либо введите ключ восстановления.
