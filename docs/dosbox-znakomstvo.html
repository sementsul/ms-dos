DOSBox: эмулятор DOS на современном ПК

DOSBox 0.72+ эмулирует PC с DOS: запускает игры и программы 90-х на Windows 10/11, где настоящий DOS невозможен.

Детали

  • Ставится за минуту, настроек по умолчанию хватает для игр.
  • Окно 320x200 масштабируется, звук Sound Blaster эмулируется.
  • MBFU использует DOSBox для копирования файлов на флешку.

Итог

Для игр качайте свежий DOSBox-X или DOSBox Staging — там точнее эмуляция.

Читайте также

  • Команда MOUNT в DOSBox
  • Скорость эмуляции: cycles
  • Файл dosbox.conf
  • Образы дисков: IMGMOUNT
