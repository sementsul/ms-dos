How the program came about

The project grew from a practical task: making a bootable USB stick with real MS-DOS 5.00 or 6.22 on a modern computer. Existing tools either work with FreeDOS or require manual fiddling with partitioning, the boot sector and system files. The first version of MBFU was a graphical utility with open source code — it is still in the repository under the MIT licence.

Version 2.0 was rewritten from scratch: DOSBox 0.72 with a custom menu runs inside, so the program can not only write an image but also clone media, capture an image from a disk or floppy and edit the contents of an image with ordinary DOS commands.

Why 2.0 is closed source

Version 1.x was open and stays open: its MIT licence cannot be revoked. With 2.0 the situation differs — it is work that is sold, and open code would mean anyone could publish a build under their own name. So 2.0 ships without source and is distributed under the licence agreement.

What stays open and verifiable: the .mbfu image format is publicly documented, third-party components (DOSBox, SDL) ship under their own licences, and every build can be checked against a published SHA-256.

Principles

  • No MS-DOS or other third-party files in the package — only own code and openly licensed components.
  • No telemetry and no network calls: the program runs offline.
  • No subscription: one purchase, one licence for one computer.
  • Mistakes are admitted plainly: if something does not work on your hardware, the answer says so.
