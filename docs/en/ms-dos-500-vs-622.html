MS-DOS 5.00 vs 6.22: which one to put on a USB drive

The choice between MS-DOS 5.00 and 6.22 is not about which is newer. It is about which machine the stick will be plugged into and what size media it has to handle. Both fit on a single floppy, and both boot from a USB stick prepared with an image.

What MS-DOS 5.00 brought

Version 5.00 was a large step. It introduced EDIT, a full-screen text editor that replaced the line editor EDLIN for everyday work, and QBASIC, a structured BASIC interpreter with a built-in editor. It added HIMEM.SYS as the standard way to manage extended memory, and it allowed DOS itself to load above 640 KB on 286 and later processors, freeing conventional memory.

It also added a shell and UNDELETE, and it made the memory story understandable: HIMEM.SYS loaded the XMS driver, and DOS could then be placed in the high memory area.

What 6.x and 6.22 added

The 6.x line added the maintenance tools most people now associate with DOS. SCANDISK replaced CHKDSK as the thorough disk checker, DEFRAG defragmented disks, and MSAV provided antivirus scanning. Memory handling improved with MEMMAKER, which automated the CONFIG.SYS and AUTOEXEC.BAT tuning that used to be done by hand. DriveSpace replaced DoubleSpace, and 6.22 is the version that shipped with DriveSpace in place.

6.22 is also the last standalone release of MS-DOS, which is why it became the reference version for boot disks and DOS-based tools.

The practical answer

For modern hardware and larger media, choose 6.22. It has the disk tools you need when a card or stick misbehaves, and its memory manager is easier to configure.

For a period-correct machine, choose 5.00. On a 286 or an early 386 with a small hard disk, 5.00 is lighter and matches the hardware. For very old machines, 3.3 remains the safe choice: it works on hardware that predates the 286 memory model and does not need HIMEM.SYS.

What not to expect

Neither version turns a modern PC into a retro machine. USB boot support depends on the BIOS, and some boards will not boot from a stick prepared this way. Test the boot before you rely on it.

Step by step

  1. Check the target machine. Note the processor class, the BIOS boot options and the size of the disk or card you need to work with.
  2. Pick the version. 6.22 for modern hardware and larger media, 5.00 for a period 286 or 386, 3.3 for very old machines.
  3. Prepare the image. Create an .mbfu image and add or edit files with DOS commands inside it before writing anything to the stick.
  4. Write and test. Write the image to the USB stick, boot the target machine from it, and confirm the DOS prompt appears before using it on real data.

Questions

Can I run 6.22 on a 286?
It will boot, but MEMMAKER and some tools expect a 386 or later. On a 286, 5.00 is the more comfortable fit.

Does 6.22 need more memory?
The base system is comparable. The difference is the extra tools, which you do not have to load unless you run them.

Which version should a boot stick use?
6.22 for maintenance work, because SCANDISK and DEFRAG are on the same disk. 5.00 if the stick is meant for a specific period machine.
