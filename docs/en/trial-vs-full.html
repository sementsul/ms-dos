Why the Trial is limited by time, not by features

A cut-down demo cannot answer the important question: will the image write to your particular USB stick and will your machine boot from it. So the trial build has every operation, and the only limit is 30 days from first start. That is normally enough to check everything that matters.

How the period is counted

The first start writes a local mark into the user profile (%APPDATA%\MBFU\trial.json) and into shared program data (%PROGRAMDATA%\MBFU\trial.json). From then on the program counts the remaining days using the system clock. If the clock is moved back by more than two days, the record is treated as tampered with and the trial mode stops.

The counter sends nothing over the network: no telemetry, no identifiers. What is stored on disk is listed on the Privacy page.

What happens after 30 days

The program stops running operations and shows a link to Boosty. Your images, USB sticks and files are untouched — the limit concerns the utility itself.

Moving to the full version

There is no in-place upgrade: the Trial and the full version are separate builds. After paying on Boosty you download a build without the counter, unpack it into a separate folder and work. No key to enter; the old Trial folder can be deleted.

Questions

Is the Trial a cut-down program?

No. All four operations are available from day one, including image creation and editing in DOSBox.

Can the Trial be extended?

No, the period is fixed. If 30 days were not enough to test on your hardware, write to sementsul.maksim@yandex.ru.

Are my images preserved when I switch?

Yes. .mbfu and .img files are ordinary files in the folder you chose; they do not depend on the program version.
