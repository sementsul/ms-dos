Updating the BIOS from a DOS USB drive

This is the one job on this site that can leave a machine unusable if it goes wrong. The procedure is short; the preparation is what makes it safe.

Before you start

A BIOS update rewrites the firmware that starts the board. If the write is interrupted the board may not POST, and recovery depends on what the vendor built in: a Flashback port, a second BIOS chip, a socketed chip.

Update for a reason - a CPU the board does not recognise yet, a fixed bug, a security advisory. If the vendor offers a Windows utility for your board, use it: the DOS route is for boards where only a DOS flasher is published, or where Windows will not start.

Identify the board and the current version

  • Read the exact model and revision from the board or its box; vendors ship different firmware for revisions that share a name.
  • msinfo32 shows BaseBoard Product, BaseBoard Version and BIOS Version/Date.
  • Compare them with the vendor's support page and read the release notes.
  • Write the current version down; it is how you confirm afterwards that the flash worked.

Download and verify the package

Take the file only from the vendor's support page for your model. A DOS package is usually a ZIP with the flasher, the firmware file (.rom or .bin), sometimes a batch file and a readme.

  • Compare the published checksum with the download - Get-FileHash -Algorithm SHA256 in PowerShell.
  • Unpack the archive; do not flash from inside it.
  • Read the readme: some vendors require a cleared CMOS or a particular utility version.

Prepare the DOS USB drive

Use a stick of 4 GB or less, or a larger one with a FAT16 first partition. Write your MS-DOS image with MBFUTool as administrator, choose Write MS-DOS image to USB flash, select the image and the device, and confirm. Everything on the stick is erased; the steps are in the USB guide.

Copy the vendor files onto the stick

  • Copy the flasher and the firmware file to the root of the stick.
  • Keep the vendor's file names; renaming a .rom file can make the flasher reject it.

Boot in Legacy/CSM mode

The DOS flasher is a real-mode program: the firmware must be in Legacy or CSM mode, Secure Boot must be off, and you must pick the USB entry without a "UEFI:" prefix. On many boards the stick appears twice, and the UEFI entry leads to a black screen. Secure Boot and CSM covers the settings per vendor.

Run the flasher

  1. At the DOS prompt, find the stick's letter with dir; it is often not C:.
  2. Run the vendor's executable or batch file.
  3. Confirm the board model and the version before pressing the key that starts the write.
  4. Do not touch the keyboard or the power button while erase and write blocks are on screen; a blank display is normal.
  5. Wait for the completion message or the automatic reboot. Do not reset the machine yourself.

After the reboot

  • Load the defaults if the vendor asks, then set the date, SATA mode and boot order.
  • Re-enable Secure Boot and the TPM if Windows 11 needs them.
  • Verify the new version on the POST screen and in setup.
  • With BitLocker on, expect a recovery-key prompt; have the key ready.

Safety rules

  • Use a UPS, or a charged battery on a laptop: a power cut during the write is the failure that matters.
  • Verify the checksum and never flash a file from a forum or from another model's page.
  • Do not run a DOS flasher from Windows or from DOSBox.
  • If the board does not POST, stop power-cycling it and look up the vendor's recovery procedure.

Step by step

  1. Identify the board. Read the model and revision from the board or box, and note the current BIOS version.
  2. Download the package. Get the flasher and firmware from the vendor page for that model, then compare the checksum.
  3. Write the DOS stick. Use a stick of 4 GB or less and write your own MS-DOS image as administrator.
  4. Copy the files. Put the flasher and the firmware file in the root of the stick under their original names.
  5. Boot in Legacy mode. Disable Secure Boot, enable CSM, choose the USB entry without the UEFI prefix.
  6. Run the flasher and wait. Confirm the model and version, then leave the machine alone until it reboots.

Questions

Can I flash the BIOS from a DOSBox window?
No. DOSBox emulates a machine, so the flasher writes nothing to the real chip; it must run on the actual board.

What happens if the power fails during the flash?
The board may not start. Recovery depends on a Flashback port, a backup BIOS chip or service reprogramming.

Will the update erase my BIOS settings?
Usually yes; most updates load defaults. Note the SATA mode, boot order and overclocking settings first.

Do I need the newest version or the one for my revision?
The one for your exact model and revision; newer is not always compatible with older revisions.
