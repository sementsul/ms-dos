Tools for writing MS-DOS images to USB: an honest comparison

Most comparisons of USB writers compare marketing pages. Here is what each program does with an MS-DOS image, and where each one stops.

The job has two shapes

"Make a bootable DOS stick" covers two operations. Either you have an image - a byte-for-byte copy of a floppy or disk - and need it written to the device, or you have a folder of DOS files and need a boot sector and system files built around them. Some tools do the first, some the second; choosing the wrong family is why a tool seems not to work.

Rufus

Rufus is free, open source and Windows-only. It is very good at what most people need: writing modern ISO images to USB, and creating a FreeDOS stick from the files it bundles. Its partition scheme options - MBR/BIOS versus GPT/UEFI - are the switch that decides whether a DOS stick can boot.

For MS-DOS, Rufus includes no Microsoft files. It writes an image you supply, or uses DOS files from a folder, but the MS-DOS part stays your responsibility - a licensing boundary, not a defect.

WinSetupFromUSB

WinSetupFromUSB is built around installing Windows from USB, from the XP era to current releases, and handles the boot-menu work multi-source installers need. It is right when the job is a Windows installer, or a stick offering both Windows setup and a DOS entry. It is not an image writer for an arbitrary MS-DOS image.

HP USB Disk Storage Format Tool

A small, old utility that formats a stick as FAT or FAT32 and can copy DOS system files from a folder to make it bootable. It works with files, not images: it cannot open an .img, .ima or .mbfu, and it does not check what it wrote. Its FAT32 option is useless for MS-DOS, but it still helps when you have DOS files and no imaging tool.

dd and Win32DiskImager

These write an image byte for byte. dd on Linux, macOS or Windows through WSL is the classic form: dd if=image.img of=/dev/sdX bs=4M status=progress. Win32DiskImager is the Windows equivalent with a device picker.

Both are honest and dangerous for the same reason: point them at the wrong device and it is gone. Neither compares the device with the image as part of the write. Win32DiskImager reports that the write call returned, which is not verification; a read-back is a separate step.

MBFUTool 2.0

MBFUTool is image-oriented and does exactly four things: Write MS-DOS image to USB flash, Create MBFU image from disk/floppy/USB, Clone MS-DOS disk/floppy/USB to USB, and Edit MS-DOS image with DOS commands. Editing runs in the bundled DOSBox 0.72 with a BEN menu.

Its .mbfu format is a container with a header, zlib compression and a SHA-256 digest of the raw image, and the program verifies that digest - the step the dd family leaves to you. It needs administrator rights, blocks writes to the system disk, and destroys the target stick's data. It ships no MS-DOS files: the image is yours, per the licensing page. Limits are FAT16: 4 GB maximum, 2 GB in practice, no image above 4 GB in DOSBox 0.72, Latin-only paths.

Pick by task

  • A FreeDOS stick in two minutes - Rufus.
  • A Windows installer, or Windows plus a DOS entry - WinSetupFromUSB.
  • A folder of DOS files and nothing else - HP USB Disk Storage Format Tool.
  • An exact copy of an image, verified by hand - dd or Win32DiskImager.
  • Your own MS-DOS image, written, verified, cloned and editable - MBFUTool 2.0.

Match the tool to what you are holding - an image or a folder of files - and to whether you need verification, cloning or editing afterwards. That decides whether the stick boots, which matters more than a feature list.

Step by step

  1. Decide what you have. An image file and a folder of DOS files need different tools; note which one you have.
  2. Check the target media. The stick needs a FAT16 partition and an MBR partition table for a BIOS boot. Back it up first.
  3. Write or create. Write the image byte for byte, or create a boot sector and copy the system files.
  4. Verify the result. Compare the device with the image, or check the stored hash if the tool keeps one.
  5. Test on real hardware. A successful write is not a successful boot; try the stick on the target machine.

Questions

Does Rufus include MS-DOS?
No. It bundles FreeDOS, a different operating system. For MS-DOS you supply your own files or image.

Which of these tools verifies the write?
MBFUTool verifies the SHA-256 digest stored in its .mbfu container. With dd or Win32DiskImager, verification is a manual read-back.

Can I use these tools on macOS or Linux?
dd works everywhere. Rufus, WinSetupFromUSB, the HP tool, Win32DiskImager and MBFUTool are Windows programs.
