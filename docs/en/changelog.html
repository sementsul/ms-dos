Version history and updates

Version dated 18 November 2026.

What changes in 2.x, how updates ship and what to do if a new build does not suit you. Version 2.x is the current branch; the 1.x line stays open and is kept as an archive only.

Update policy

  • Critical 2.x fixes are free for every buyer and appear in the same private Boosty post as the build.
  • New numbering (2.1, 2.2) costs nothing within 2.x.
  • A move to 3.x, if it ever happens, would be a separate product — the 2.x licence you bought stays valid.
  • Builds are not code-signed, so every release comes with a fresh SHA-256 on the “How to verify the build” page.

2.0.0 — November 2026

The first public release of the new line.

  • Four operations: write an MS-DOS image to USB, create a .mbfu image, clone media to USB, edit an image with DOS commands.
  • DOSBox 0.72 inside, with a custom menu and Russian/English interface.
  • Own image format .mbfu: zlib compression, SHA-256 integrity check.
  • Streaming write to the device with hash verification afterwards.
  • Writing to the system disk is blocked; three confirmations before data is destroyed.
  • Trial mode: 30 days, every feature, no key and no network.
  • PyInstaller onedir build, so antivirus products complain less often.

1.x — archive

The first line was an open-source utility: pick a drive, write a bootable MS-DOS 5.00/6.22 USB stick, with safety checks before formatting. The sources remain in the repository under the MIT licence, which cannot be revoked for versions already published. Ready-made 1.x builds are in Releases.

1.x is no longer developed: fixes and new features land in 2.x only.

How to update

  1. Download the new build from the private Boosty post.
  2. Verify the SHA-256 against the page “How to verify the build”.
  3. Unpack the archive into a new folder — not over the old one.
  4. Start the new version and check that your images open.
  5. Delete the old folder once you are satisfied.

Settings do not carry over: the program keeps no profile except the trial mark. .mbfu and .img files stay where you saved them.

Reporting a bug

Write to sementsul.maksim@yandex.ru with the program version, Windows version, the USB stick and motherboard model, what you did and what happened. If it reproduces, list the steps; attach a screenshot if you have one.

Under consideration

Plans change, so this lists directions rather than promised dates: support for additional image formats, better diagnostics during writing, and more documentation on working with images on old hardware.
