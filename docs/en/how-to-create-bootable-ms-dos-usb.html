How to create a bootable MS-DOS USB drive

A bootable MS-DOS stick is a FAT16 partition with the system files in the right place. Here is the whole path: the hardware, a lawful image, writing it on Windows, and checking that it boots.

What you need

  • A USB stick of up to 4 GB, or a larger stick with a FAT16 first partition; the FAT16 limits page explains why.
  • Your own lawful MS-DOS image: floppies you imaged yourself, a subscription copy, or media you own.
  • A Windows x64 computer, administrator rights and a USB port the firmware will boot from. Formatting and boot-sector writes both need elevation.

Writing erases the whole stick. Copy anything you need elsewhere and unplug USB disks you want to keep: the tool lists physical devices, not drive letters.

Where to get MS-DOS lawfully

MBFUTool ships no MS-DOS files: support ended in 2001, there is no official free download, and the system files are Microsoft's. You supply an image you may lawfully use:

  • the subscriber catalogue at my.visualstudio.com, for some subscription levels;
  • floppies or a boxed copy you own;
  • a machine that still runs MS-DOS, whose disk you image before the hardware dies.

"MS-DOS 6.22 ISO" files from file-sharing sites are counterfeit whatever you paid for the tool. The rules are on the licensing page.

Write the image

  1. Start MBFUTool as administrator; without elevation the write is refused.
  2. Choose Write MS-DOS image to USB flash.
  3. Select the image: .img, .ima or .mbfu. Paths with Cyrillic characters must be moved to a Latin-only folder first.
  4. Select the target from the list of physical disks and check its size and model twice.
  5. Confirm. The stick is partitioned as FAT16, the boot sector is written, the system files are copied.

The program refuses to write to the system disk; that guard protects the machine, not the stick.

Verify the boot

  1. Reboot and open the one-time boot menu: F12, F11, F8 or Esc.
  2. Pick the USB entry without a "UEFI:" prefix. If only UEFI entries exist, see Secure Boot and CSM.
  3. Expect a DOS prompt or the image's menu within seconds.
  4. Run dir and ver; write a small file to check the volume is writable.

If it does not boot: symptom and what to check

Find the symptom, then work through the causes in the order given.

SymptomWhat to check
Black screen, the PC moves on to the next deviceUEFI-only mode: enable CSM or Legacy boot and disable Secure Boot.
Non-System disk or disk errorNo IO.SYS/MSDOS.SYS on the volume, or the firmware booted another device. Rewrite, then check the boot order.
Invalid media typeThe active partition is NTFS or exFAT, or its boot sector is damaged. Recreate it as FAT16.
Missing operating systemNo active partition: the partition table is wrong or was overwritten.
The stick is missing from the boot menuUSB boot disabled, Fast Boot on, or a port that cannot boot. Try a rear USB 2.0 port.
Cannot exceed 4GB for FAT16The stick is larger than 4 GB. Use a smaller one or a 2 GB FAT16 first partition.

The error guide covers each message in more detail.

What the tool does, and what it does not

MBFUTool 2.0 is a Windows x64 program with four operations: Write MS-DOS image to USB flash, Create MBFU image from disk/floppy/USB, Clone MS-DOS disk/floppy/USB to USB, and Edit MS-DOS image with DOS commands, which runs in the bundled DOSBox 0.72 with a BEN menu. The .mbfu container holds a header, zlib-compressed data and a SHA-256 digest of the raw image.

It does not ship, download or install MS-DOS. Images are FAT16, so a partition stops at 4 GB and 2 GB in practice; DOSBox cannot mount one above 4 GB; paths must be Latin-only. The trial runs 30 days, offline and without a key: trial details.

Step by step

  1. Back up the stick. Copy anything you need off the drive; writing replaces the partition table.
  2. Get a lawful image. Use your own floppy or disk image, or a copy from a Visual Studio subscription.
  3. Run as administrator. Choose Write MS-DOS image to USB flash as administrator, pick the image and the physical device, confirm.
  4. Boot from the stick. Open the boot menu, choose the entry without the UEFI prefix, check that DOS starts.

Questions

Do I need FreeDOS for this?
No. FreeDOS is a separate operating system with its own files. It is quicker for a DOS-like command line, but it is not MS-DOS.

Does MBFUTool include MS-DOS?
No. It writes, captures, clones and edits images. The system files come from your own lawful copy.

Will the stick boot on a UEFI-only laptop?
No. Without CSM the firmware only runs EFI programs, and MS-DOS has no EFI version.
