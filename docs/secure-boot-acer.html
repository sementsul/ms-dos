Secure Boot на Acer

Отключить Secure Boot на Acer: F2 — Security — сначала задайте Supervisor Password, иначе пункт Secure Boot заблокирован.

Пошагово

  1. F2 — вкладка Security.
  2. Set Supervisor Password — задайте пароль (запишите!).
  3. Появится Secure Boot — Disabled.
  4. Boot — Boot Mode: Legacy для MS-DOS.
  5. F10 — сохранить. Пароль потом можно сбросить тем же пунктом.

Нюанс

Без пароля супервизора Acer не дает трогать Secure Boot — это их фирменная особенность.

Вопросы и ответы

Забыл Supervisor Password — что теперь?
Сбросить его дома почти нереально: пароль хранится в NVRAM. Обращайтесь в сервис Acer с чеком.

Можно ли удалить пароль после настройки?
Да: Security — Set Supervisor Password, введите текущий и оставьте новый пустым.
