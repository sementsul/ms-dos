Secure Boot на ASUS

Отключить Secure Boot на ASUS: вход клавишами Del или F2, далее Advanced Mode (F7) — вкладка Boot — Secure Boot — OS Type: Other OS. Именно Other OS отключает проверку подписей.

Пошагово

  1. Перезагрузите ПК и жмите Del/F2 до входа в UEFI.
  2. Нажмите F7 (Advanced Mode), откройте вкладку Boot.
  3. Пункт Secure Boot: в OS Type выберите Other OS (не Windows UEFI).
  4. Для загрузки MS-DOS дополнительно включите CSM/Legacy в Boot.
  5. F10 — сохранить и выйти.

Нюанс

На части плат ASUS пункт Secure Boot появляется только после установки пароля администратора BIOS.

Вопросы и ответы

Что выбрать: Windows UEFI Mode или Other OS?
Other OS — именно этот пункт отключает проверку подписей Secure Boot на ASUS. Windows UEFI Mode, наоборот, требует подписанный загрузчик.

Пункт Secure Boot неактивен — что делать?
На части плат сначала задайте Administrator Password в разделе Security: без него пункт заблокирован. Пароль запишите.
