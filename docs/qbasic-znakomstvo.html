QBASIC: Бейсик из комплекта MS-DOS

QBASIC.EXE — редактор и интерпретатор QuickBASIC из MS-DOS 5.0/6.22. Пишете программу, жмете F5 — она выполняется.

Детали

  • Запуск: QBASIC без параметров — пустой редактор.
  • F5 — выполнить, Shift+F5 — перезапустить.
  • В комплекте справка и примеры.

Итог

Для компиляции в EXE нужен полный QuickBASIC 4.5 — QBASIC только интерпретирует.
