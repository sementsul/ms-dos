AUTOEXEC.BAT: автозапуск DOS

Пакетный файл в корне: выполняется после CONFIG.SYS — PATH, PROMPT, SMARTDRV, KEYRUS, запуск NC.

Детали

  • @ECHO OFF — первой строкой, чтобы не мусорить.
  • PATH C:\DOS;C:\NC
  • WIN — так стартовали Windows 3.x.

Итог

MBFU дописывает сюда запуск Norton Commander автоматически.
