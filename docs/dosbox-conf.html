Файл dosbox.conf

Все настройки DOSBox: [sdl] окно/звук, [cpu] cycles, [autoexec] команды при старте. MBFU генерирует его из cfg.conf.

Детали

  • Правьте блокнотом, комментарии внутри на английском.
  • Свой конфиг: dosbox -conf my.conf.
  • Копия рабочего конфига спасает после переустановки.

Итог

Ломать не страшно: удалили — DOSBox создаст дефолт заново.
