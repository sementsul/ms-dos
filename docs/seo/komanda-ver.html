Команда VER

VER показывает версию DOS: 5.00 или 6.22. Десять секунд — и вы знаете, что загрузилось.

Синтаксис

VER

Примеры

VER

Узнать версию.

Типичные ошибки

  • Программы смотрят версию через API, а не через VER — но цифры те же.
  • SETVER умеет подменять версию для капризных программ.

Вопросы и ответы

VER врет на Windows 9x?
VER покажет версию Windows (4.x), а API отдаст 7.x — особенность гибрида.

Зачем знать версию?
Драйверы и игры эпохи привязаны к версиям: 6.22 ест почти все, 5.0 — легче.
