MS-DOS 3.x: сети и дискеты 1.44 (1984–1988)

Версии 3.x: дискеты 1.2 МБ и 1.44 МБ, разделы FAT16 до 32 МБ, сетевые функции, XCOPY. Самая долгоживущая ветка.

Детали

  • 3.3 (1987) — стандарт для 286/386.
  • XCOPY — копирование деревьями.
  • Compaq DOS 3.31 — разделы больше 32 МБ.

Итог

На 3.3 работало почти все ПО эпохи 386.
