Команда QBASIC

QBASIC — редактор и интерпретатор Бейсика из MS-DOS 5.0+. Пишете код, F5 — выполняется. Компиляции в EXE нет (это умеет полный QuickBASIC).

Синтаксис

QBASIC [/EDITOR] [/NOHI] [/RUN программа] [программа.BAS]

Все параметры

КлючЧто делает
/EDITORТолько редактор без запуска.
/NOHIБез ярких цветов (совместимость).
/RUN программаСразу выполнить и выйти.

Примеры

QBASIC

Пустой редактор.

QBASIC GORILLA.BAS

Открыть игру-пример.

QBASIC /RUN TEST.BAS

Выполнить скрипт.

Типичные ошибки

  • Файлы .BAS — обычный текст, правятся любым редактором.
  • Русские буквы — кодовая страница 866 + KEYRUS.

Вопросы и ответы

QBASIC и QuickBASIC — одно и то же?
Нет: QBASIC — бесплатный интерпретатор из DOS, QuickBASIC 4.5 — полный продукт с компилятором.

Где взять примеры?
GORILLA.BAS и NIBBLES.BAS лежали рядом с QBASIC.EXE — откройте через File — Open.
