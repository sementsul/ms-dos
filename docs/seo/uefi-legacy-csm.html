UEFI, Legacy и CSM для загрузки DOS

MS-DOS не знает UEFI: грузиться надо в Legacy/CSM-режиме. Ищите в BIOS: Boot Mode → Legacy, CSM → Enabled, Secure Boot → Disabled.

Детали

  • UEFI only — DOS не загрузится никогда.
  • Legacy/CSM + MBR-флешка — рабочая связка.
  • На части ноутбуков Legacy вырезан — тогда только старый ПК или эмулятор.

Итог

Сохраняйте настройки F10 и выбирайте флешку через Boot Menu.
