Secure Boot на Gigabyte

Отключить Secure Boot на Gigabyte: Del — вкладка BIOS — Secure Boot — Disabled, плюс CSM Support: Enabled для загрузки DOS.

Пошагово

  1. Del при включении, вкладка BIOS.
  2. CSM Support — Enabled (иначе Legacy-загрузка невозможна).
  3. Secure Boot — Disabled.
  4. В Boot Option выберите вашу флешку.
  5. F10 — сохранить и выйти.

Нюанс

Gigabyte часто прячет Secure Boot, пока не выставлен CSM Enabled — делайте по порядку.

Вопросы и ответы

Это безопасно?
Да, если вернуть Secure Boot обратно после работы с DOS.
