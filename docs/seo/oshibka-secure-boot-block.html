Блокировка Secure Boot

UEFI отказывается грузить неподписанный загрузчик MS-DOS.

Причины

  • Secure Boot включен (так по умолчанию на всех ПК с Windows 8+).

Решение

  1. Отключите Secure Boot в UEFI (инструкции по вендорам — в соседних статьях).
  2. Для MS-DOS также включите Legacy/CSM-режим.
