Команда DEBUG

DEBUG — отладчик машинного кода: ассемблирование (A), дампы (D), ввод (E), трассировка (T), точки (G). Через него правили сектора и писали tiny-утилиты.

Синтаксис

DEBUG [[диск:][путь]файл [параметры]]

Все параметры

КлючЧто делает
A [адрес]Ассемблировать инструкции.
D [диапазон]Дамп памяти.
E адрес [значения]Ввести байты.
RРегистры и флаги.
T [=адрес] [число]Трассировка по шагам.
G [=адрес]Выполнить до точки.
U [диапазон]Дизассемблировать.
N имя / L / WИмя файла, загрузка, запись.
QВыход.
H числаHex+dec калькулятор.
M, C, F, SКопировать, сравнить, заполнить, найти в памяти.
I/O портВвод/вывод в порты.
XA/XD/XM/XSРабота с EMS.

Примеры

DEBUG

Пустой сеанс.

H 10 20

0x10 = 16 dec, сумма/разность.

D 0:0 FF

Дамп таблицы векторов.

Типичные ошибки

  • Одна опечатка в E — и правите не ту память. Сначала D, потом E.
  • W без N перезапишет файл программы — держите копии.

Вопросы и ответы

Что можно сделать DEBUG без ассемблера?
Смотреть дампы, править байты в файлах, считать hex, чинить boot-сектор.

Почему DEBUG нет в 64-бит Windows?
NTVDM вырезан. Пользуйтесь DOSBox или флешкой MBFU.
