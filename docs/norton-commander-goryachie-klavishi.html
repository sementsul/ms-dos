Горячие клавиши Norton Commander

Минимум для жизни: F1 помощь, F3 просмотр, F4 правка, F5 копировать, F6 перенести, F7 каталог, F8 удалить, F10 выход.

Детали

  • F3 — встроенный просмотрщик любых файлов.
  • F4 — встроенный редактор.
  • Alt+F5 — упаковать, Alt+F6 — распаковать архив.
  • Ctrl+Enter — имя файла в командную строку.
