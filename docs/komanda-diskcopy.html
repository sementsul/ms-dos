Команда DISKCOPY

DISKCOPY делает побайтовый клон дискеты: загрузчик, FAT, все дорожки. С одним дисководом просит менять дискеты.

Синтаксис

DISKCOPY [диск1: [диск2:]] [/1] [/V]

Все параметры

КлючЧто делает
/1Копировать только первую сторону.
/VПроверка записи.

Примеры

DISKCOPY A: A:

Клон с одним дисководом.

DISKCOPY A: B:

С двумя дисководами без перекидываний.

Типичные ошибки

  • Дискета-приемник обязана быть того же типа.
  • Для жестких дисков и флешек DISKCOPY не подходит — там XCOPY/образы.

Вопросы и ответы

DISKCOPY или COPY *.*?
DISKCOPY — точный клон с загрузчиком, COPY — просто файлы. Загрузочная дискета — только DISKCOPY.

Сколько раз менять дискеты с одним дисководом?
Несколько проходов: DOS гоняет данные через память.
