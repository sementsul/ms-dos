NTFS и MS-DOS

NTFS для DOS — чужой: чтение только через драйвер NTFS4DOS (Avira), записи лучше избегать. Загрузиться с NTFS DOS не может.

Факты

  • Чтение: драйвер NTFS4DOS.
  • Запись: рискованна.
  • Загрузка: нет.

Вывод

Держите DOS-раздел FAT16, а NTFS-раздел — для обмена с Windows.
