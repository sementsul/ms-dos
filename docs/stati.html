Norton Commander

  • Установка Norton Commander на флешку
    Norton Commander 4.0 ставится на загрузочную флешку одной галочкой MBFU: файлы ложатся в D:\NC, а в AUTOEXEC.BAT добавляется запуск NC.EXE.
  • Интерфейс Norton Commander: две панели
    Экран NC — две файловые панели, меню сверху, строка команд снизу и подсказки F-клавиш. Левая/правая панели независимы: источник и приемник операций.
  • Горячие клавиши Norton Commander
    Минимум для жизни: F1 помощь, F3 просмотр, F4 правка, F5 копировать, F6 перенести, F7 каталог, F8 удалить, F10 выход.
  • Просмотр файлов: F3
    Встроенный вьювер NC открывает тексты, а с плагинами — картинки, таблицы и базы. Листание стрелками, поиск F7.
  • Редактор NC: F4
    Встроенный редактор проще EDIT: подсветки нет, но для правки CONFIG.SYS и BAT-файлов хватает за глаза.
  • Копирование и перенос: F5/F6
    F5 копирует помеченное на другую панель, F6 — переносит (копия + удаление). Маски и дерево каталогов поддерживаются.
  • Архивы в Norton Commander
    NC открывает ZIP/ARJ/LHA как каталоги: зашел, скопировал наружу — распаковал. Упаковка — Alt+F5.
  • Norton Commander против DOS Shell
    Штатная оболочка DOSSHELL из MS-DOSIBE 5.0/6.x мышью и меню проигрывает NC в скорости: две панели и клавиши решают.

QBASIC

  • QBASIC: Бейсик из комплекта MS-DOS
    QBASIC.EXE — редактор и интерпретатор QuickBASIC из MS-DOS 5.0/6.22. Пишете программу, жмете F5 — она выполняется.
  • Первая программа на QBASIC
    Классика за минуту: PRINT выводит текст, INPUT спрашивает, CLS чистит экран.
  • Редактор QBASIC: правка и запуск
    Синий экран, меню сверху: File (сохранить), Run (запустить), Debug (точки останова). Ошибки подсвечиваются сразу при вводе.
  • Графика QBASIC: SCREEN 13
    SCREEN 13 — режим 320x200, 256 цветов: PSET ставит точку, LINE рисует линии, CIRCLE — круги.
  • Gorilla и Nibbles: игры из QBASIC
    С QBASIC шли исходники двух игр: Gorilla (банановая дуэль на QBasic-физике) и Nibbles (змейка на двоих). Лучший учебник: игра + ее код.

DOSBox

  • DOSBox: эмулятор DOS на современном ПК
    DOSBox 0.72+ эмулирует PC с DOS: запускает игры и программы 90-х на Windows 10/11, где настоящий DOS невозможен.
  • Команда MOUNT в DOSBox
    MOUNT связывает папку Windows с буквой DOS: MOUNT C C:\GAMES — после этого C: внутри эмулятора — ваша папка.
  • Скорость эмуляции: cycles
    Старые игры рассчитаны на 386/486: на полной скорости носятся. Параметр cycles задает темп.
  • Файл dosbox.conf
    Все настройки DOSBox: [sdl] окно/звук, [cpu] cycles, [autoexec] команды при старте. MBFU генерирует его из cfg.conf.
  • Образы дисков: IMGMOUNT
    IMGMOUNT монтирует ISO/образы дискет как CD-ROM или дисковод: игры с дисков идут без распаковки.

Память и железо

  • Барьер 640 КБ: почему памяти вечно не хватало
    Первые 640 КБ — conventional memory для DOS и программ. Все, что выше, — верхняя, расширенная (XMS) и EMS. Ошибка «Insufficient memory» — про эти 640
  • HIMEM.SYS: доступ к расширенной памяти
    Драйвер XMS из MS-DOS 5.0+: открывает память выше 1 МБ и верхние блоки. Без него Windows 3.x и половина игр не стартуют.
  • EMM386: верхняя память и EMS
    Драйвер для 386+: раздает UMB (куда грузят драйверы командой DEVICEHIGH) и эмулирует EMS из XMS.
  • CONFIG.SYS: настройка загрузки DOS
    Текстовый файл в корне: драйверы (DEVICE), FILES/BUFFERS, DOS=HIGH, меню загрузки. Читается при старте до AUTOEXEC.
  • AUTOEXEC.BAT: автозапуск DOS
    Пакетный файл в корне: выполняется после CONFIG.SYS — PATH, PROMPT, SMARTDRV, KEYRUS, запуск NC.
  • Звук в DOS: Sound Blaster
    Стандарт де-факто: SET BLASTER=A220 I7 D1 (+ адрес, IRQ, DMA). Без этой строки игры молчат или виснут на тесте звука.

Версии MS-DOS

  • Что такое MS-DOS простыми словами
    MS-DOS (Microsoft Disk Operating System) — операционная система для IBM PC 1981–2000 годов: черный экран, командная строка, программы запускаются по и
  • История MS-DOS: от QDOS до 6.22
    1980: Тим Патерсон пишет QDOS за 6 недель. 1981: Microsoft покупает ее за $50–75 тыс. и продает IBM как PC DOS 1.0. Дальше — версии 2.x–6.22, война с
  • MS-DOS 1.x: начало (1981–1982)
    Первая версия: только дискеты 160–320 КБ, одна сторона, каталогов еще нет (появились в 2.0), файловая система FAT12.
  • MS-DOS 2.x: каталоги и жесткие диски (1983–1984)
    Версия 2.0 принесла дерево каталогов, перенаправление, поддержку HDD до 10–32 МБ и пакетные файлы с FOR/GOTO.
  • MS-DOS 3.x: сети и дискеты 1.44 (1984–1988)
    Версии 3.x: дискеты 1.2 МБ и 1.44 МБ, разделы FAT16 до 32 МБ, сетевые функции, XCOPY. Самая долгоживущая ветка.
  • MS-DOS 4.x: неудачная ветка (1988–1989)
    Версия 4.0/4.01: разделы до 2 ГБ, графическая оболочка DOSSHELL, но слава глючной. Многие сидели на 3.3 до выхода 5.0.
  • MS-DOS 5.0: зрелость (1991)
    Легендарная 5.0: EDIT, QBASIC, HIMEM.SYS, загрузка ядра выше 640 КБ, поддержка 2.88-МБ дискет. Именно ее ставит MBFU в режиме /MSD5.
  • MS-DOS 6.0: DoubleSpace и антивирус (1993)
    Версия 6.0: сжатие диска DoubleSpace, SCANDISK еще нет (был CHKDSK), MSAV-антивирус, MemMaker, игры Gorilla/Nibbles в QBASIC.
  • MS-DOS 6.2: SCANDISK (1993)
    В 6.2 появился SCANDISK вместо CHKDSK, починили DoubleSpace. Промежуточная, но уже рабочая версия.
  • MS-DOS 6.22: последняя классика (1994)
    Финальная отдельная MS-DOS: DriveSpace вместо скандального DoubleSpace, максимум стабильности. Именно ее ставит MBFU в режиме /MSD6.
  • MS-DOS 7.x и 8.0 внутри Windows
    MS-DOS 7.0 (Windows 95) и 7.1 (98, +FAT32!), 8.0 (Me, DOS-режим уже кастрирован). Отдельно не продавались.
  • Клоны DOS: FreeDOS, DR-DOS, PC DOS
    MS-DOS не одинока: FreeDOS (открытый, живой, FAT32/LFN), DR-DOS (конкурент 90-х), IBM PC DOS (7.1, 2000). Для ретро-железа все годятся.

Сравнение

  • MBFU против Rufus для MS-DOS
    Rufus умеет FreeDOS из коробки, а MS-DOS 6.22 — только если подсунуть свои файлы и знать ключи. MBFU заточена под MS-DOS: разметка, MBR, SYS и NC из к
  • MBFU против Ventoy для DOS
    Ventoy грузит ISO пачками, но настоящий DOS с записью на флешку — не его профиль: DOS в ISO обычно read-only. MBFU делает полноценную R/W-систему.
  • MBFU против UNetbootin
    UNetbootin ставит Linux-дистрибутивы, DOS там гость сбоку. Для MS-DOS он не предназначен.
  • Загрузочная флешка FreeDOS через Rufus
    Если MS-DOS-лицензии нет, а DOS нужен: Rufus + FreeDOS — легально и бесплатно.
  • Запись DOS-образа через dd и Win32DiskImager
    Готовый IMG-образ льют побайтово: Linux — dd, Windows — Win32DiskImager или Rufus в режиме DD.

Гайды

  • Как создать загрузочную флешку MS-DOS
    Пошагово через MBFU: скачать, запустить от администратора, принять лицензии, выбрать флешку до 4 ГБ, ввести букву, подтвердить, дождаться Done.
  • UEFI, Legacy и CSM для загрузки DOS
    MS-DOS не знает UEFI: грузиться надо в Legacy/CSM-режиме. Ищите в BIOS: Boot Mode → Legacy, CSM → Enabled, Secure Boot → Disabled.
  • Клавиши Boot Menu и BIOS у производителей
    Быстрый выбор загрузки, не меняя настроек: ASUS/MSI — F8/F11, Gigabyte — F12, Lenovo — F12/Fn+F12, HP — Esc→F9, Dell — F12, Acer — F12.
  • Проверка загрузочной флешки без перезагрузки
    Быстрые проверки: файлы на месте (COMMAND.COM, NC), буква доступна на запись, MBR валиден. Полная — загрузка на тестовом ПК.
  • DOS и Windows на одной флешке
    Схема: первый раздел FAT16 активный с DOS (до 4 ГБ), второй — NTFS/exFAT с Windows-образами и драйверами. Грузитесь с первого.
  • USB 2.0 против 3.0 для DOS-флешки
    DOS и BIOS лучше дружат с USB 2.0: старые BIOS могут не увидеть флешку в синем порту 3.x. Втыкайте в черный порт 2.0.
  • Какую флешку взять под MS-DOS
    Идеал: 1–4 ГБ, USB 2.0, без шифрования и U3-софта. MS-DOS 6.22 + NC занимают ~15 МБ — остальное под игры и файлы.
