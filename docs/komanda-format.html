Команда FORMAT

FORMAT создает файловую систему на диске. Ключ /S сразу делает диск загрузочным (переносит системные файлы), /Q — быстрая очистка оглавления, /U — безусловное полное форматирование.

Синтаксис

FORMAT диск: [/V[:метка]] [/Q] [/U] [/F:размер] [/B | /S] [/T:дорожки /N:секторы] [/1] [/4] [/8] [/C]

Все параметры

КлючЧто делает
/V[:метка]Метка тома до 11 символов.
/QБыстрое: чистит FAT и корень, поверхность не трогает.
/UБезусловное: нельзя отменить через UNFORMAT.
/F:размерРазмер дискеты: 360, 720, 1.2, 1.44, 2.88.
/SСделать диск загрузочным (системные файлы).
/BОставить место под системные файлы (потом SYS).
/1Односторонняя дискета.
/4Форматировать 360-КБ дискету в дисководе 1.2 МБ.
/88 секторов на дорожку (для старых дискет).
/CПерепроверить кластеры, помеченные сбойными.

Примеры

FORMAT A: /S

Загрузочная дискета.

FORMAT A: /F:720

Дискета 720 КБ в дисководе 1.44.

FORMAT D: /Q /V:MSDOS

Быстрое форматирование флешки с меткой.

Типичные ошибки

  • FORMAT уничтожает все данные — перепроверьте букву диска дважды.
  • «Invalid media type» — раздел не DOS-овский: сначала FDISK.
  • Флешки больше 4 ГБ в FAT16 не форматируются — лимит файловой системы.

Вопросы и ответы

Чем /Q отличается от обычного FORMAT?
/Q только чистит таблицы, bad-блоки не ищет. Для новой дискеты нужен полный проход.

Как сделать загрузочную флешку вручную?
FORMAT D: /S — но проще MBFU: она еще разметит диск и запишет MBR.
