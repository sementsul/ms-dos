Secure Boot на HP

Отключить Secure Boot на HP: Esc — F10 (BIOS Setup) — Security — Secure Boot Configuration — снять галочку, ввести код подтверждения.

Пошагово

  1. При включении жмите Esc, затем F10.
  2. Security — Secure Boot Configuration.
  3. Снимите Secure Boot, введите цифры подтверждения с экрана.
  4. Advanced — Boot Options: Legacy Support Enable для DOS.
  5. F10 — сохранить.

Нюанс

HP требует ввод кода из 4 цифр — защита от случайного отключения.

Вопросы и ответы

Какой код вводить при отключении?
HP показывает 4 цифры прямо на экране подтверждения — введите их и Enter. Это защита от случайных изменений.

Чем Legacy Support отличается от Secure Boot?
Legacy Support разрешает загрузку не-UEFI систем (наш случай), Secure Boot проверяет подписи. Для DOS нужно: Legacy Enable + Secure Boot Disable.
