Secure Boot на MSI

Отключить Secure Boot на MSI: Del при старте — Settings — Security — Secure Boot — Disabled. Путь почти всегда через раздел Settings.

Пошагово

  1. Войдите в BIOS клавишей Del.
  2. Откройте Settings — Security.
  3. Secure Boot — переключите в Disabled.
  4. Для MS-DOS включите Boot Mode: Legacy+UEFI и USB Boot.
  5. F10 — сохранить.

Нюанс

На платах MSI с Click BIOS интерфейс графический — ищите иконку Security слева.

Вопросы и ответы

Где искать Secure Boot в Click BIOS?
Settings — Security. На старых версиях путь бывает Boot — Secure Boot. Ориентир: иконка с замком.

После отключения не грузится Windows — почему?
Windows 11 требует Secure Boot. Верните Enabled после работы с DOS-флешкой — настройки меняются за минуту.
