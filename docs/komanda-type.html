Команда TYPE

TYPE выводит текстовый файл на экран. Быстрый просмотр README, BAT и CONFIG без редактора.

Синтаксис

TYPE файл

Примеры

TYPE C:\README.TXT

Прочитать ридми.

TYPE AUTOEXEC.BAT | MORE

Постранично.

TYPE A.TXT+B.TXT

TYPE тоже умеет склейку при выводе.

Типичные ошибки

  • Двоичный файл через TYPE — мусор на экране и писк динамика. Ctrl+C останавливает.
  • Длинный файл уносится вверх — добавляйте | MORE.

Вопросы и ответы

TYPE или EDIT?
TYPE — глянуть, EDIT/F3 в NC — править. Не путайте.

Как вывести файл на принтер?
TYPE FILE.TXT > PRN — перенаправление на устройство.
