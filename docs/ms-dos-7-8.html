MS-DOS 7.x и 8.0 внутри Windows

MS-DOS 7.0 (Windows 95) и 7.1 (98, +FAT32!), 8.0 (Me, DOS-режим уже кастрирован). Отдельно не продавались.

Детали

  • 7.1 понимает FAT32 и большие диски.
  • 8.0 запрещает загрузку в чистый DOS с HDD.
  • VER врет про версию Windows — смотрите API.

Итог

Для настоящего DOS ставьте 6.22, а не потроха Windows.
