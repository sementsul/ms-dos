Команда DIR

DIR показывает список файлов и каталогов: имена, размеры, даты. Это самая частая команда DOS — без нее не понять, что лежит на диске и куда вы попали.

Синтаксис

DIR [диск:][путь][имя_файла] [/P] [/W] [/A[[:]атрибуты]] [/O[[:]порядок]] [/S] [/B] [/L]

Все параметры

КлючЧто делает
/PПостраничный вывод: пауза после каждого экрана.
/WКраткий вывод в несколько колонок: только имена.
/AПоказать файлы с атрибутами: D каталоги, R только чтение, H скрытые, A архивные, S системные. Пример: DIR /A:H.
/OСортировка: N по имени, E по расширению, D по дате, S по размеру, G сначала каталоги. Пример: DIR /O:-S (сначала большие).
/SВключая все подкаталоги.
/BГолый формат: только имена, удобно для перенаправления в файл.
/LИмена строчными буквами.

Примеры

DIR

Все в текущем каталоге.

DIR C:\DOS /W

Компактный список каталога DOS.

DIR *.TXT /S /P

Все текстовые файлы дерева постранично.

DIR /A:H

Показать скрытые файлы.

DIR /O:-D

Сначала самые свежие.

Типичные ошибки

  • Маска *. * — это все файлы, а *.* без точки в DOS не работает как в Windows.
  • «File not found» при маске — норма: совпадений просто нет.
  • Русские имена в кодировке 866: набирайте их так же, иначе не найдет.

Вопросы и ответы

Как посмотреть скрытые и системные файлы?
DIR /A — покажет все, включая скрытые (H) и системные (S). По умолчанию DIR их прячет.

Как сохранить список файлов в файл?
DIR /S /B > LIST.TXT — перенаправление работает со всеми командами.
