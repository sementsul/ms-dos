DOS и Windows на одной флешке

Схема: первый раздел FAT16 активный с DOS (до 4 ГБ), второй — NTFS/exFAT с Windows-образами и драйверами. Грузитесь с первого.

Детали

  • Разметка: любой менеджер разделов, флаг boot на FAT16.
  • DOS второй раздел не увидит — это нормально.
  • Файлы между мирами таскайте через FAT16-раздел.

Итог

Сложный вариант — GRUB4DOS-меню, но обычно хватает двух разделов.
