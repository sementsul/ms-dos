Команда SYS

SYS делает диск загрузочным без форматирования: переносит IO.SYS, MSDOS.SYS и COMMAND.COM. Первый параметр (откуда брать систему) можно опускать — возьмет с текущего диска.

Синтаксис

SYS [диск1:][путь] диск2:

Примеры

SYS C:

Сделать диск C: загрузочным.

SYS A: C:

Перенести систему с дискеты на C:.

Типичные ошибки

  • Версия SYS обязана совпадать с версией переносимых файлов, иначе «Non-System disk».
  • На диске должно хватать места в начале: IO.SYS требует первые записи корня.
  • Скрытые системные файлы обычным COPY не перенести — только SYS.

Вопросы и ответы

SYS или FORMAT /S — что лучше?
FORMAT /S — для нового диска, SYS — когда данные на диске нужно сохранить.

Почему после SYS диск все равно не грузится?
Проверьте: раздел активный (FDISK), версии совпадают, BIOS грузится с этого диска.
