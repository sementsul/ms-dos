Команда PROMPT

PROMPT настраивает приглашение командной строки. Коды с $: $P путь, $G знак >, $T время, $D дата, $V версия.

Синтаксис

PROMPT [текст]

Все параметры

КлючЧто делает
$PТекущий диск и путь.
$GЗнак >.
$TВремя.
$DДата.
$VВерсия DOS.
$NТолько диск.
$L/$B< и |.
$Q=.
$HЗабой.
$EEsc.
$_Перевод строки.
$$Знак $.

Примеры

PROMPT $P$G

Знаменитое C:\>.

PROMPT [$T] $P$G

Приглашение с часами.

PROMPT $N:$G

Минимализм: только диск.

Типичные ошибки

  • PROMPT без параметров сбрасывает к стандартному.
  • Храните любимый PROMPT в AUTOEXEC.BAT.

Вопросы и ответы

Как сделать приглашение с новой строки?
PROMPT $_$P$G — код $_ разрывает строку.

Откуда берется C:\> по умолчанию?
Это и есть $P$G, заданный при старте.
