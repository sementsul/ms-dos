## 2. Блокеры до публикации

1. **Почтовый адрес.** ФИО, ИНН и e-mail заполнены; адрес для корреспонденции
   публикуется как «предоставляется по запросу на e-mail» (`SELLER["address"]`
   пуст, работает `seller_address()`). Это компромисс: ст. 10 ЗоЗПП и ст. 26.1
   требуют адрес, а раскрывать домашний адрес самозанятого не всегда разумно.
   Если готовы опубликовать адрес — впишите его в `tools/site_config.py`,
   и все страницы обновятся сами. Для ЕС (DSA, ст. 30) публикация адреса
   предпочтительнее.
2. **Уведомление Роскомнадзора** о начале обработки ПД (ст. 22 152-ФЗ).
   Подаётся через Госуслуги до начала обработки. Без него обработка аналитики
   формально неправомерна, даже при согласии.
3. **Цена на Boosty.** Сайт не публикует цену (она на Boosty), но в оферте
   должно быть однозначно: разовая покупка, а не подписка. Текст уже приведён
   к этому виду — проверьте, что страница Boosty не противоречит.
4. **Установщик собран** (`trial/installer/MBFUTool_2.0_Trial_Setup.exe`,
   10,4 МБ, SHA-256 `98e686a4…2a7f6897`). Проверены установка, состав файлов,
   хэши файлов и корректный откат каталога. Тихая деинсталляция требует
   подтверждения UAC — это нормально для установки в Program Files.
   Пересборка: `ISCC.exe MBFU_TRIAL.iss` из папки `trial`.
5. **Ключ GitHub / доступ к репозиторию.** Пуш не выполнялся: сетевой доступ
   из этой среды к GitHub не работает (TLS). См. `DEPLOY.md`.

## 3. Что стоит сделать в ближайшее время (не блокеры)

### Россия

- **Локализация ПД.** Сайт на GitHub Pages (США), аналитика Google (США) и
  Яндекс (РФ). По 152-ФЗ первичная запись ПД должна идти в базу на территории
  РФ. Счётчики cookie не хранят ПД на нашем сервере, поэтому риск умеренный,
  но в политике трансграничная передача описана — этого достаточно только при
  честном основании. Если появятся формы (подписка, обратная связь), хостинг
  нужно перенести в РФ.
- **Чеки НПД.** Чек формируется в «Мой налог» не позднее 9-го числа месяца,
  следующего за расчётом; при безналичной оплате — до 9-го числа. Покупатель
  должен получить чек по e-mail.
- **Маркировка рекламы** не требуется: платных размещений нет.
- **Возраст.** Продажа 18+, политика запрещает использование детьми; для ЕС
  это соответствует практике (нет обработки данных детей).

### США

- **DMCA-агент.** Для использования safe harbor по § 512 нужна регистрация
  агента в Copyright Office (платно, раз в 3 года). Сейчас есть только
  контакт в `/dmca.html` — без регистрации safe harbor не действует.
- **COPPA.** Сайт не для детей; возрастной гейт не требуется, но формулировка
  в политике уже есть.
- **Штатные законы (CCPA/CPRA и др.).** Продажи данных нет, GPC учитывается;
  отдельная страница «Do Not Sell» не нужна, права перечислены в политике.
- **FTC.** Все заявления о функциях должны быть проверяемыми; на сайте нет
  «самый быстрый», «100% совместим» и т. п. Обещания обновлений ограничены
  версией 2.x — это указано.

### Европейский союз

- **Представитель в ЕС (ст. 27 GDPR).** При систематическом предложении
  товаров лицам в ЕС нужен представитель в Союзе (или отказ от рынка ЕС).
  Пока его нет — это осознанный риск; при росте продаж в ЕС назначьте
  представителя (услуга от ~€100–300/год).
- **VAT на цифровые услуги.** Продажа частным лицам в ЕС — НДС страны
  покупателя (OSS). Boosty — российская платформа и, вероятно, НДС ЕС не
  удерживает. Нужна консультация бухгалтера; альтернатива — продавать через
  площадку, которая берёт VAT на себя.
- **ODR.** Платформа онлайн-разрешения споров ЕС закрыта с 20 июля 2025 года,
  поэтому ссылка не ставится — в `/refund.html` указаны потребительские центры.
- **DSA.** Нужна точка контакта для властей и пользователей — e-mail в
  `/contacts.html` подходит; для «торговца» требуется самоудостоверение
  (st. 30) — реквизиты уже публикуются.
- **EAA.** Заявление о доступности опубликовано; барьеры устраняются по
  обращениям.

## 4. Пробная сборка (Trial): правовые особенности

- Пробный период **30 дней**, все функции, без ключа; данные о строке —
  только дата первого запуска и подписанный счётчик, без ПД
  (`%APPDATA%\MBFU\trial.json`, `%PROGRAMDATA%\MBFU\trial.json`,
  `HKCU\Software\MBFU\Trial`). Это описано в EULA, п. 2.
- Признаки изменения файлов ведут к блокировке (`tampered`) — это защита
  лицензии, а не сбор данных.
- В Trial нет телеметрии и сетевых запросов; проверка интернета не требуется.
- Сборка не подписана: антивирусы могут ругаться. Это честно указано на
  сайте и в README — предупреждение снижает риск претензий.

## 5. Проверка перед публикацией

```powershell
python tools/gen_site.py       # печатает блокеры по реквизитам
python tools/gen_seo.py
python tools/gen_sitemap.py
python tools/check_site.py     # ссылки, JSON-LD, alt, токены
```

`check_site.py` должен завершиться с `0 with problems`. После замены реквизитов
в `tools/site_config.py` блокеры исчезнут, и сайт можно публиковать.
