How to verify the MBFUTool build

Version dated 18 November 2026.

The build is not code-signed, so antivirus products sometimes warn. You can confirm in a minute that the file was not altered on the way: compare its SHA-256 with the value published here.

1. Compare the SHA-256

Open PowerShell in the folder with the installer and run:

Get-FileHash .\MBFUTool_2.0_Trial_Setup.exe -Algorithm SHA256

Compare the result with the published value:

FileSizeSHA-256
MBFUTool_2.0_Trial_Setup.exe{{TRIAL_SIZE}}{{TRIAL_SHA}}

The value is also published in SHA256SUMS.txt next to the build.

Match — the file is intact. Mismatch — download again: the transfer may have been interrupted, or the file did not come from ms-dos.su.

2. Compare the size

Size is a rough but instant check. The installer is {{TRIAL_SIZE}}. Noticeably smaller means the download did not finish.

3. Understand the antivirus reaction

The program is packaged with PyInstaller in onedir mode: an _internal folder with the executable beside it. The onefile mode — everything in one exe that unpacks itself into a temporary folder — is what heuristic engines most often flag as suspicious behaviour, which is why it was dropped.

If an antivirus still complains:

  • check the file on VirusTotal — a few engines out of seventy is a typical packer false positive;
  • exclude the program folder, not the whole drive;
  • do not disable protection entirely, and never run unknown files as administrator.

Code signing certificates cost money; until there is one, the hash on this site is the only way to prove authenticity.

4. Make sure the program does not use the network

MBFUTool works offline: it does not check for updates, send statistics or require an account. Any network monitor shows no connections opened on start. The only write outside your own files is the trial mark.

5. What the program writes to disk

  • %APPDATA%\MBFU\trial.json — first-start date and a signed day counter;
  • %PROGRAMDATA%\MBFU\trial.json — the same mark, so deleting the profile does not reset it;
  • HKCU\Software\MBFU\Trial — a backup copy of the mark;
  • a working folder next to the image — temporary files while creating or editing an image.

None of this contains personal data: only dates and a signature.
