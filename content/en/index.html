What it does

Four actions cover the whole life of an image: capture it, change it, duplicate it, write it to media. The interface is a menu in DOSBox, driven by the arrow keys and Enter, with no pop-up windows and no console flicker.

Writing

Write an image to USB

The stick is formatted through MSDOSBOOT and the image files are copied by DOS itself. Works with floppy images and with hard-disk images alike.

Capture

Capture an image as .mbfu

A container of our own: header, zlib compression and SHA-256. Ordinary .img, .ima, .vhd and .vfd files are read and written as well.

Cloning

Clone media

Moves the contents of an MS-DOS disk or floppy onto a prepared USB stick — no manual shuffling of drive letters.

Editing

Edit in DOSBox

The image opens as A: or C:, so copy, del, md, rd and edit all work. Changes to a .mbfu are written back into the image.

How it works

The program is a DOSBox window with a menu plus a set of Windows system operations. Nothing is installed into the system apart from the program itself.

  1. Choose an image or a disk. A standard Windows dialog opens, or a menu listing the drives: model, size, letter.
  2. Preparation. The image is unpacked into a temporary folder, the partition table is checked, and the target stick is formatted.
  3. Copying. Files are moved with COPY inside DOSBox — that is what keeps the stick bootable.
  4. Verification. The status screen shows that copying finished rather than hanging.
  5. Result. The stick boots in Legacy/CSM mode with Secure Boot switched off.

Will a stick larger than 4 GB work?

Yes. DOSBox cannot mount images larger than 4 GB, so larger media get a DOS partition of roughly 4 GB formatted as FAT16.

Why won't my PC boot from the stick?

MS-DOS has no UEFI support. You need Legacy/CSM mode and Secure Boot switched off. Instructions for ASUS, MSI, Gigabyte, Lenovo, HP, Dell and Acer are in the Guides.
